# Kirova 23

A static website: index.html contains the HTML and CSS; assets/ contains all images and the regular and bold PT Sans fonts. No JavaScript, packages, build step, or external stylesheets are required.

Run `python3 -m http.server 8000` in this folder and open http://127.0.0.1:8000/.

Vercel is connected to the GitHub repository and deploys changes pushed to main.
